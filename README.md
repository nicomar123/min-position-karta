# Min Position Karta

En enkel webbapp som låter dig hitta din position, lägga till markeringar på en karta och spara korta anteckningar om dina favoritplatser.

## Funktioner
- Använd webbläsarens geolokalisering för att flyga kartan till din aktuella position.
- Klicka var som helst på kartan för att skapa en markering och lägg till egna anteckningar.
- Dra markeringar för att uppdatera deras position och håll koll på dina platser i listan.
- Rensa alla markeringar och anteckningar med ett klick.

## Kom igång
1. Öppna `index.html` i din webbläsare.
2. Tillåt åtkomst till din plats när webbläsaren frågar (valfritt, men behövs för att automatiskt hitta din position).
3. Klicka på kartan eller använd knappen "Hitta min position" för att skapa markeringar och anteckningar.

Appen använder [Leaflet](https://leafletjs.com) tillsammans med OpenStreetMap-data som levereras via CDN, så en internetuppkoppling krävs för kartplattor.
